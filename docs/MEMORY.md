## 🛠️ 2. Critical Guidelines & Standard Practices

### 2.1 प्रोजेक्टर विजिबिलिटी नियम (Projector Visibility Rule)
- प्रोजेक्टर पर पतला टेक्स्ट (`font-weight: 300/400`) और हल्के रंग बिल्कुल नहीं दिखते।
- प्रत्येक सिमुलेटर के प्रेक्षण पैनल, टेक्स्ट लेबल और समीकरणों को **बोल्ड (`font-weight: 800-900`)**, पर्याप्त बड़ा (`16px-22px`), और गहरे रंगों (`#0f172a`, `#166534`, `#991b1b`) में रखना अनिवार्य है।

### 2.2 टोकन बचत एवं पुन: प्रयोज्यता नियम (Ponytail Token Efficiency)
- बार-बार एक ही कोड दोहराने या अनावश्यक व्याख्या में टोकन बर्बाद करने के बजाय, दोहराए जाने वाले कार्यों हेतु पायथन टूल्स का उपयोग करें।
- सभी मानक टूल्स और ओपन-सोर्स पैटर्न (`PhET`, `Virtua-Chem-Sim`, `GSAP`) का उपयोग सीधे सिमुलेटरों में करें।

### 2.3 PowerShell इनलाइन कोट्स से बचना
- कभी भी PowerShell में इनलाइन पायथन (`python -c "..."`) न चलाएं। सदैव एक स्टैंडअलोन `.py` स्क्रिप्ट बनाकर निष्पादित करें।

### 2.4 टाइमर आइसोलेशन
