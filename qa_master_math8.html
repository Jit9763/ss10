त्रिकोणमिति के मूलभूत सूत्र एवं संकल्पनाएँ (Core Concepts)
1. अनुपात (समकोण त्रिभुज)
$\sin\theta = \frac{\text{Perpendicular}}{\text{Hypotenuse}}$, $\cos\theta = \frac{\text{Base}}{\text{Hypotenuse}}$
$\tan\theta = \frac{\text{Perpendicular}}{\text{Base}}$, $\cot\theta = \frac{\text{Base}}{\text{Perpendicular}}$
$\sec\theta = \frac{\text{Hypotenuse}}{\text{Base}}$, $\csc\theta = \frac{\text{Hypotenuse}}{\text{Perpendicular}}$
2. तीन मौलिक सर्वसमिकाएँ
1. $\sin^2\theta + \cos^2\theta = 1$
2. $1 + \tan^2\theta = \sec^2\theta$
3. $1 + \cot^2\theta = \csc^2\theta$
3. विशिष्ट कोणों के मान
$\sin 0^\circ = 0$, $\sin 30^\circ = \frac{1}{2}$, $\sin 45^\circ = \frac{1}{\sqrt{2}}$
$\sin 60^\circ = \frac{\sqrt{3}}{2}$, $\sin 90^\circ = 1$
$\tan 30^\circ = \frac{1}{\sqrt{3}}$, $\tan 45^\circ = 1$, $\tan 60^\circ = \sqrt{3}$
4. पाइथागोरस प्रमेय
$\text{Hypotenuse}^2 = \text{Perpendicular}^2 + \text{Base}^2$
$k^2 = p^2 + b^2$
प्रश्नावली 8.1: त्रिकोणमितीय अनुपात (संपूर्ण 11 प्रश्न)
प्रश्न 1 $\triangle ABC$ में, जिसका कोण $B$ समकोण है, $AB = 24\text{ cm}$ और $BC = 7\text{ cm}$ है। निम्नलिखित का मान ज्ञात कीजिए:
(i) $\sin A, \cos A$      (ii) $\sin C, \cos C$
चरण 1: पाइथागोरस प्रमेय से कर्ण $AC$
$AC = \sqrt{AB^2 + BC^2} = \sqrt{24^2 + 7^2} = \sqrt{576 + 49} = \sqrt{625} = 25\text{ cm}$
चरण 2: (i) कोण $A$ के सापेक्ष अनुपात
कोण $A$ के लिए: सम्मुख भुजा (लंब) $= BC = 7$, संलग्न भुजा (आधार) $= AB = 24$, कर्ण $= 25$
$\sin A = \frac{BC}{AC} = \mathbf{\frac{7}{25}}$, \quad $\cos A = \frac{AB}{AC} = \mathbf{\frac{24}{25}}$
चरण 3: (ii) कोण $C$ के सापेक्ष अनुपात
कोण $C$ के लिए: सम्मुख भुजा (लंब) $= AB = 24$, संलग्न भुजा (आधार) $= BC = 7$, कर्ण $= 25$
$\sin C = \frac{AB}{AC} = \mathbf{\frac{24}{25}}$, \quad $\cos C = \frac{BC}{AC} = \mathbf{\frac{7}{25}}$
उत्तर: (i) $\sin A = \frac{7}{25}, \cos A = \frac{24}{25}$; \quad (ii) $\sin C = \frac{24}{25}, \cos C = \frac{7}{25}$

लंब / सम्मुख भुजा ($p$): 7 आधार / संलग्न भुजा ($b$): 24
कर्ण ($k = \sqrt{p^2 + b^2}$)

प्रश्न 2 दी गई आकृति में $\tan P - \cot R$ का मान ज्ञात कीजिए, जहाँ $PQ = 12\text{ cm}, PR = 13\text{ cm}$ और $\angle Q = 90^\circ$ है।
चरण 1: पाइथागोरस से $QR$ की गणना
$QR = \sqrt{PR^2 - PQ^2} = \sqrt{13^2 - 12^2} = \sqrt{169 - 144} = \sqrt{25} = 5\text{ cm}$
चरण 2: $\tan P$ और $\cot R$ का मान
$\angle P$ के लिए: सम्मुख भुजा $= QR = 5$, संलग्न भुजा $= PQ = 12 \implies \tan P = \frac{5}{12}$
$\angle R$ के लिए: संलग्न भुजा $= QR = 5$, सम्मुख भुजा $= PQ = 12 \implies \cot R = \frac{5}{12}$
चरण 3: अभीष्ट अंतर
$\tan P - \cot R = \frac{5}{12} - \frac{5}{12} = \mathbf{0}$
उत्तर: $\tan P - \cot R = \mathbf{0}$
प्रश्न 3 यदि $\sin A = \frac{3}{4}$, तो $\cos A$ और $\tan A$ का मान परिकलित कीजिए।
चरण 1: त्रिभुज की भुजाएँ
$\sin A = \frac{\text{Perpendicular}}{\text{Hypotenuse}} = \frac{3}{4} \implies \text{Perpendicular} = 3k, \text{Hypotenuse} = 4k$
आधार $= \sqrt{\text{Hypotenuse}^2 - \text{Perpendicular}^2} = \sqrt{(4k)^2 - (3k)^2} = \sqrt{16k^2 - 9k^2} = \sqrt{7}k$
चरण 2: $\cos A$ और $\tan A$ निकालना
$\cos A = \frac{\text{Base}}{\text{Hypotenuse}} = \mathbf{\frac{\sqrt{7}}{4}}$
$\tan A = \frac{\text{Perpendicular}}{\text{Base}} = \mathbf{\frac{3}{\sqrt{7}}}$
उत्तर: $\cos A = \mathbf{\frac{\sqrt{7}}{4}}$, \quad $\tan A = \mathbf{\frac{3}{\sqrt{7}}}$
प्रश्न 4 यदि $15\cot A = 8$ हो, तो $\sin A$ और $\sec A$ का मान ज्ञात कीजिए।
चरण 1: अनुपात और भुजाएँ
$15\cot A = 8 \implies \cot A = \frac{8}{15} = \frac{\text{Base}}{\text{Perpendicular}}$
माना आधार $= 8k$, लंब $= 15k$
कर्ण $= \sqrt{(8k)^2 + (15k)^2} = \sqrt{64k^2 + 225k^2} = \sqrt{289k^2} = 17k$
चरण 2: $\sin A$ और $\sec A$ की गणना
$\sin A = \frac{\text{Perpendicular}}{\text{Hypotenuse}} = \mathbf{\frac{15}{17}}$
$\sec A = \frac{\text{Hypotenuse}}{\text{Base}} = \mathbf{\frac{17}{8}}$
उत्तर: $\sin A = \mathbf{\frac{15}{17}}$, \quad $\sec A = \mathbf{\frac{17}{8}}$
प्रश्न 5 यदि $\sec\theta = \frac{13}{12}$ हो, तो अन्य सभी त्रिकोणमितीय अनुपात परिकलित कीजिए।
चरण 1: तीनों भुजाएँ
$\sec\theta = \frac{\text{Hypotenuse}}{\text{Base}} = \frac{13}{12} \implies \text{Hypotenuse} = 13k, \text{Base} = 12k$
लंब $= \sqrt{13^2 - 12^2} = \sqrt{169 - 144} = \sqrt{25} = 5k$
चरण 2: सभी 5 अन्य अनुपात
$\sin\theta = \frac{5}{13}, \quad \cos\theta = \frac{12}{13}, \quad \tan\theta = \frac{5}{12}$
$\csc\theta = \frac{13}{5}, \quad \cot\theta = \frac{12}{5}$
उत्तर: $\sin\theta = \frac{5}{13}, \cos\theta = \frac{12}{13}, \tan\theta = \frac{5}{12}, \csc\theta = \frac{13}{5}, \cot\theta = \frac{12}{5}$
प्रश्न 6 यदि $\angle A$ और $\angle B$ न्यून कोण हों जहाँ $\cos A = \cos B$, तो दिखाइए कि $\angle A = \angle B$।
प्रमाण
माना समकोण $\triangle ABC$ में कोण $C = 90^\circ$ है।
तब कोण $A$ के लिए: $\cos A = \frac{AC}{AB}$
और कोण $B$ के लिए: $\cos B = \frac{BC}{AB}$
दिया है: $\cos A = \cos B \implies \frac{AC}{AB} = \frac{BC}{AB} \implies AC = BC$
चूँकि सम्मुख भुजाएँ समान हैं, अतः उनके सम्मुख कोण भी समान होंगे:
$AC = BC \implies \mathbf{\angle B = \angle A}$ अर्थात $\mathbf{\angle A = \angle B}$। (इति सिद्धम्)
उत्तर: सिद्ध हुआ कि $\mathbf{\angle A = \angle B}$
प्रश्न 7 यदि $\cot\theta = \frac{7}{8}$, तो (i) $\frac{(1+\sin\theta)(1-\sin\theta)}{(1+\cos\theta)(1-\cos\theta)}$ \quad (ii) $\cot^2\theta$ का मान निकालिए।
चरण 1: सर्वसमिका से सरलीकरण
अंश: $(1+\sin\theta)(1-\sin\theta) = 1 - \sin^2\theta = \cos^2\theta$
हर: $(1+\cos\theta)(1-\cos\theta) = 1 - \cos^2\theta = \sin^2\theta$
अतः $\frac{(1+\sin\theta)(1-\sin\theta)}{(1+\cos\theta)(1-\cos\theta)} = \frac{\cos^2\theta}{\sin^2\theta} = \cot^2\theta$
चरण 2: मान रखना
दिया है $\cot\theta = \frac{7}{8}$
(i) मान $= \cot^2\theta = \left(\frac{7}{8}\right)^2 = \mathbf{\frac{49}{64}}$
(ii) $\cot^2\theta = \mathbf{\frac{49}{64}}$
उत्तर: (i) मान = $\mathbf{\frac{49}{64}}$; \quad (ii) मान = $\mathbf{\frac{49}{64}}$
प्रश्न 8 यदि $3\cot A = 4$, तो जाँच कीजिए कि $\frac{1-\tan^2 A}{1+\tan^2 A} = \cos^2 A - \sin^2 A$ है या नहीं।
चरण 1: अनुपातों का मान
$3\cot A = 4 \implies \cot A = \frac{4}{3} \implies \tan A = \frac{3}{4}$
लंब $= 3$, आधार $= 4 \implies$ कर्ण $= \sqrt{3^2 + 4^2} = 5$
$\cos A = \frac{4}{5}, \quad \sin A = \frac{3}{5}$
चरण 2: LHS और RHS की तुलना
$\text{LHS} = \frac{1 - (3/4)^2}{1 + (3/4)^2} = \frac{1 - 9/16}{1 + 9/16} = \frac{7/16}{25/16} = \mathbf{\frac{7}{25}}$
$\text{RHS} = \cos^2 A - \sin^2 A = \left(\frac{4}{5}\right)^2 - \left(\frac{3}{5}\right)^2 = \frac{16}{25} - \frac{9}{25} = \mathbf{\frac{7}{25}}$
$\text{LHS} = \text{RHS} = \frac{7}{25}$
उत्तर: हाँ, दोनों पक्ष बराबर हैं ($\mathbf{\text{LHS} = \text{RHS} = \frac{7}{25}}$)।
प्रश्न 9 त्रिभुज $ABC$ में, जिसका कोण $B$ समकोण है, यदि $\tan A = \frac{1}{\sqrt{3}}$, तो निम्नलिखित के मान ज्ञात कीजिए:
(i) $\sin A \cos C + \cos A \sin C$      (ii) $\cos A \cos C - \sin A \sin C$
चरण 1: भुजाएँ ज्ञात करना
$\tan A = \frac{1}{\sqrt{3}} \implies BC = 1, AB = \sqrt{3}$
कर्ण $AC = \sqrt{1^2 + (\sqrt{3})^2} = \sqrt{1 + 3} = 2$
अतः कोण $A$: $\sin A = \frac{1}{2}, \cos A = \frac{\sqrt{3}}{2}$
कोण $C$: $\sin C = \frac{\sqrt{3}}{2}, \cos C = \frac{1}{2}$
चरण 2: गणनाएँ
(i) $\sin A \cos C + \cos A \sin C = \left(\frac{1}{2} \times \frac{1}{2}\right) + \left(\frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2}\right) = \frac{1}{4} + \frac{3}{4} = \mathbf{1}$
(ii) $\cos A \cos C - \sin A \sin C = \left(\frac{\sqrt{3}}{2} \times \frac{1}{2}\right) - \left(\frac{1}{2} \times \frac{\sqrt{3}}{2}\right) = \frac{\sqrt{3}}{4} - \frac{\sqrt{3}}{4} = \mathbf{0}$
उत्तर: (i) मान = $\mathbf{1}$; \quad (ii) मान = $\mathbf{0}$
प्रश्न 10 $\triangle PQR$ में, जिसका कोण $Q$ समकोण है, $PR + QR = 25\text{ cm}$ और $PQ = 5\text{ cm}$ है। $\sin P, \cos P$ और $\tan P$ के मान ज्ञात कीजिए।
चरण 1: पाइथागोरस से $PR$ और $QR$ ज्ञात करना
माना $QR = x\text{ cm} \implies PR = 25 - x$
पाइथागोरस प्रमेय से: $PR^2 = PQ^2 + QR^2$
$(25 - x)^2 = 5^2 + x^2 \implies 625 - 50x + x^2 = 25 + x^2$
$625 - 25 = 50x \implies 50x = 600 \implies x = 12\text{ cm}$
अतः $QR = 12\text{ cm}$ तथा कर्ण $PR = 25 - 12 = 13\text{ cm}$
चरण 2: अनुपातों का मान
$\sin P = \frac{QR}{PR} = \mathbf{\frac{12}{13}}$
$\cos P = \frac{PQ}{PR} = \mathbf{\frac{5}{13}}$
$\tan P = \frac{QR}{PQ} = \mathbf{\frac{12}{5}}$
उत्तर: $\sin P = \mathbf{\frac{12}{13}}, \quad \cos P = \mathbf{\frac{5}{13}}, \quad \tan P = \mathbf{\frac{12}{5}}$

प्रश्न 11 बताइए कि निम्नलिखित कथन सत्य हैं या असत्य। कारण सहित अपने उत्तर की पुष्टि कीजिए:
(i) $\tan A$ का मान सदैव $1$ से कम होता है।
❌ असत्य: समकोण त्रिभुज में लंब आधार से बड़ा भी हो सकता है, जैसे $\tan 60^\circ = \sqrt{3} \approx 1.732 > 1$।
(ii) कोण $A$ के किसी मान के लिए $\sec A = \frac{12}{5}$।
✔️ सत्य: $\sec A = \frac{\text{Hypotenuse}}{\text{Base}}$ होता है। चूँकि कर्ण ($12$) आधार ($5$) से बड़ा है, अतः यह संभव है ($\sec A \ge 1$ सदैव)।
(iii) $\cos A$, कोण $A$ के $\text{cosecant}$ के लिए प्रयुक्त एक संक्षिप्त रूप है।
❌ असत्य: $\cos A$, कोण $A$ के $\text{cosine}$ का संक्षिप्त रूप है। $\text{cosecant}$ का संक्षिप्त रूप $\csc A$ होता है।
(iv) $\cot A$, $\cot$ और $A$ का गुणनफल होता है।
❌ असत्य: $\cot A$ कोण $A$ का कोटैंजेंट है, यह गुणनफल नहीं बल्कि एक संक्रिया/अनुपात है। बिना कोण के $\cot$ अर्थहीन है।
(v) किसी भी कोण $\theta$ के लिए $\sin\theta = \frac{4}{3}$।
❌ असत्य: $\sin\theta = \frac{\text{Perpendicular}}{\text{Hypotenuse}}$ होता है और किसी समकोण त्रिभुज में लंब कभी कर्ण से बड़ा नहीं हो सकता। अतः $\sin\theta \le 1$ सदैव। यहाँ $\frac{4}{3} > 1$ असंभव है।
उत्तर: (i) असत्य, (ii) सत्य, (iii) असत्य, (iv) असत्य, (v) असत्य
प्रश्नावली 8.2: विशिष्ट कोणों के त्रिकोणमितीय मान (संपूर्ण 4 प्रश्न)
प्रश्न 1 निम्नलिखित के मान निकालिए:
(i) $\sin 60^\circ \cos 30^\circ + \sin 30^\circ \cos 60^\circ$
$= \left(\frac{\sqrt{3}}{2}\right)\left(\frac{\sqrt{3}}{2}\right) + \left(\frac{1}{2}\right)\left(\frac{1}{2}\right) = \frac{3}{4} + \frac{1}{4} = \frac{4}{4} = \mathbf{1}$
(ii) $2\tan^2 45^\circ + \cos^2 30^\circ - \sin^2 60^\circ$
$= 2(1)^2 + \left(\frac{\sqrt{3}}{2}\right)^2 - \left(\frac{\sqrt{3}}{2}\right)^2 = 2(1) + 0 = \mathbf{2}$
(iii) $\frac{\cos 45^\circ}{\sec 30^\circ + \csc 30^\circ}$
$= \frac{\frac{1}{\sqrt{2}}}{\frac{2}{\sqrt{3}} + 2} = \frac{\frac{1}{\sqrt{2}}}{\frac{2 + 2\sqrt{3}}{\sqrt{3}}} = \frac{\sqrt{3}}{2\sqrt{2}(\sqrt{3} + 1)} = \mathbf{\frac{3\sqrt{2} - \sqrt{6}}{8}}$
(iv) $\frac{\sin 30^\circ + \tan 45^\circ - \csc 60^\circ}{\sec 30^\circ + \cos 60^\circ + \cot 45^\circ}$
$= \frac{\frac{1}{2} + 1 - \frac{2}{\sqrt{3}}}{\frac{2}{\sqrt{3}} + \frac{1}{2} + 1} = \frac{\frac{3}{2} - \frac{2}{\sqrt{3}}}{\frac{3}{2} + \frac{2}{\sqrt{3}}} = \frac{3\sqrt{3} - 4}{3\sqrt{3} + 4} = \mathbf{\frac{43 - 24\sqrt{3}}{11}}$
(v) $\frac{5\cos^2 60^\circ + 4\sec^2 30^\circ - \tan^2 45^\circ}{\sin^2 30^\circ + \cos^2 30^\circ}$
हर में $\sin^2 30^\circ + \cos^2 30^\circ = 1$
अंश $= 5\left(\frac{1}{2}\right)^2 + 4\left(\frac{2}{\sqrt{3}}\right)^2 - (1)^2 = 5\left(\frac{1}{4}\right) + 4\left(\frac{4}{3}\right) - 1 = \frac{5}{4} + \frac{16}{3} - 1$
$= \frac{15 + 64 - 12}{12} = \mathbf{\frac{67}{12}}$
उत्तर: (i) $1$, \quad (ii) $2$, \quad (iii) $\frac{3\sqrt{2}-\sqrt{6}}{8}$, \quad (iv) $\frac{43-24\sqrt{3}}{11}$, \quad (v) $\frac{67}{12}$

चरण 1: समीकरण बनाना
$\tan(A + B) = \sqrt{3} = \tan 60^\circ \implies A + B = 60^\circ \quad \text{--- (1)}$
$\tan(A - B) = \frac{1}{\sqrt{3}} = \tan 30^\circ \implies A - B = 30^\circ \quad \text{--- (2)}$
चरण 2: समीकरणों को हल करना
समीकरण (1) और (2) को जोड़ने पर:
$(A + B) + (A - B) = 60^\circ + 30^\circ \implies 2A = 90^\circ \implies \mathbf{A = 45^\circ}$
समीकरण (1) में $A$ का मान रखने पर:
$45^\circ + B = 60^\circ \implies \mathbf{B = 15^\circ}$
उत्तर: $\mathbf{A = 45^\circ}$ तथा $\mathbf{B = 15^\circ}$
लाइव सिमुलेटर 4: $\tan(A+B)$ व $\tan(A-B)$ युगपत समीकरण सॉल्वर
योग कोण $(A+B)$ और अंतर कोण $(A-B)$ बदलकर $A$ और $B$ के मान लाइव ज्ञात कीजिए:
$(A+B)$ का कोण: $(A-B)$ का कोण:
कोण $A = \frac{(A+B) + (A-B)}{2}$
A = 45°
कोण $B = \frac{(A+B) - (A-B)}{2}$

प्रश्न 4 बताइए कि निम्नलिखित में कौन-कौन सत्य हैं या असत्य हैं। कारण सहित अपने उत्तर की पुष्टि कीजिए:
(i) $\sin(A + B) = \sin A + \sin B$
❌ असत्य: माना $A = 30^\circ, B = 60^\circ$। तब $\sin(30^\circ + 60^\circ) = \sin 90^\circ = 1$।
किंतु $\sin 30^\circ + \sin 60^\circ = \frac{1}{2} + \frac{\sqrt{3}}{2} = \frac{1+\sqrt{3}}{2} \ne 1$।
(ii) $\theta$ में वृद्धि होने के साथ $\sin\theta$ के मान में भी वृद्धि होती है।
✔️ सत्य: $0^\circ \le \theta \le 90^\circ$ के लिए, मान $0 \rightarrow \frac{1}{2} \rightarrow \frac{1}{\sqrt{2}} \rightarrow \frac{\sqrt{3}}{2} \rightarrow 1$ बढ़ता है।
(iii) $\theta$ में वृद्धि होने के साथ $\cos\theta$ के मान में भी वृद्धि होती है।
❌ असत्य: $0^\circ \le \theta \le 90^\circ$ के लिए, $\cos\theta$ का मान $1$ से घटकर $0$ हो जाता है (घटता है, बढ़ता नहीं)।
(iv) $\theta$ के सभी मानों पर $\sin\theta = \cos\theta$।
❌ असत्य: यह केवल $\theta = 45^\circ$ पर सत्य है ($\sin 45^\circ = \cos 45^\circ = 1/\sqrt{2}$)। जैसे $\theta = 30^\circ$ पर $\sin 30^\circ = 1/2 \ne \sqrt{3}/2 = \cos 30^\circ$।
(v) $A = 0^\circ$ पर $\cot A$ परिभाषित नहीं है।
✔️ सत्य: $\cot 0^\circ = \frac{\cos 0^\circ}{\sin 0^\circ} = \frac{1}{0} \implies$ अपरिभाषित (Not Defined)।
उत्तर: (i) असत्य, (ii) सत्य, (iii) असत्य, (iv) असत्य, (v) सत्य
प्रश्नावली 8.3: त्रिकोणमितीय सर्वसमिकाएँ (संपूर्ण 4 प्रश्न एवं सभी 10 सिद्ध करने वाले भाग)
प्रश्न 1 त्रिकोणमितीय अनुपातों $\sin A, \sec A$ और $\tan A$ को $\cot A$ के पदों में व्यक्त कीजिए।
1. $\csc^2 A = 1 + \cot^2 A \implies \csc A = \sqrt{1 + \cot^2 A} \implies \mathbf{\sin A = \frac{1}{\sqrt{1 + \cot^2 A}}}$
2. $\sec^2 A = 1 + \tan^2 A = 1 + \frac{1}{\cot^2 A} = \frac{\cot^2 A + 1}{\cot^2 A} \implies \mathbf{\sec A = \frac{\sqrt{1 + \cot^2 A}}{\cot A}}$
3. $\mathbf{\tan A = \frac{1}{\cot A}}$
उत्तर: $\sin A = \frac{1}{\sqrt{1+\cot^2 A}}, \quad \sec A = \frac{\sqrt{1+\cot^2 A}}{\cot A}, \quad \tan A = \frac{1}{\cot A}$
प्रश्न 2 $\angle A$ के अन्य सभी त्रिकोणमितीय अनुपातों को $\sec A$ के पदों में लिखिए।
1. $\mathbf{\cos A = \frac{1}{\sec A}}$
2. $\sin^2 A = 1 - \cos^2 A = 1 - \frac{1}{\sec^2 A} = \frac{\sec^2 A - 1}{\sec^2 A} \implies \mathbf{\sin A = \frac{\sqrt{\sec^2 A - 1}}{\sec A}}$
3. $1 + \tan^2 A = \sec^2 A \implies \mathbf{\tan A = \sqrt{\sec^2 A - 1}}$
4. $\mathbf{\cot A = \frac{1}{\tan A} = \frac{1}{\sqrt{\sec^2 A - 1}}}$
5. $\mathbf{\csc A = \frac{1}{\sin A} = \frac{\sec A}{\sqrt{\sec^2 A - 1}}}$
उत्तर: सभी 5 अनुपात $\sec A$ के पदों में रूपांतरित किए गए।
प्रश्न 3 सही विकल्प चुनिए और अपने विकल्प की पुष्टि कीजिए:
(i) $9\sec^2 A - 9\tan^2 A =$
$= 9(\sec^2 A - \tan^2 A) = 9(1) = \mathbf{9}$
🎯 सही विकल्प: (B) $9$
(ii) $(1 + \tan\theta + \sec\theta)(1 + \cot\theta - \csc\theta) =$
$= \left(1 + \frac{\sin\theta}{\cos\theta} + \frac{1}{\cos\theta}\right)\left(1 + \frac{\cos\theta}{\sin\theta} - \frac{1}{\sin\theta}\right)$
$= \frac{(\cos\theta + \sin\theta + 1)(\sin\theta + \cos\theta - 1)}{\cos\theta\sin\theta} = \frac{(\sin\theta + \cos\theta)^2 - 1^2}{\sin\theta\cos\theta} = \frac{1 + 2\sin\theta\cos\theta - 1}{\sin\theta\cos\theta} = \mathbf{2}$
🎯 सही विकल्प: (C) $2$
(iii) $(\sec A + \tan A)(1 - \sin A) =$
$= \left(\frac{1}{\cos A} + \frac{\sin A}{\cos A}\right)(1 - \sin A) = \frac{(1 + \sin A)(1 - \sin A)}{\cos A} = \frac{1 - \sin^2 A}{\cos A} = \frac{\cos^2 A}{\cos A} = \mathbf{\cos A}$
🎯 सही विकल्प: (D) $\cos A$
(iv) $\frac{1 + \tan^2 A}{1 + \cot^2 A} =$
$= \frac{\sec^2 A}{\csc^2 A} = \frac{1/\cos^2 A}{1/\sin^2 A} = \frac{\sin^2 A}{\cos^2 A} = \mathbf{\tan^2 A}$
🎯 सही विकल्प: (D) $\tan^2 A$
उत्तर: (i) (B) $9$, \quad (ii) (C) $2$, \quad (iii) (D) $\cos A$, \quad (iv) (D) $\tan^2 A$
प्रश्न 4 निम्नलिखित सर्वसमिकाएँ सिद्ध कीजिए, जहाँ वे कोण जिनके लिए व्यंजक परिभाषित है, न्यून कोण हैं:
(i) सिद्ध कीजिए: $(\csc\theta - \cot\theta)^2 = \frac{1 - \cos\theta}{1 + \cos\theta}$
$\text{LHS} = \left(\frac{1}{\sin\theta} - \frac{\cos\theta}{\sin\theta}\right)^2 = \frac{(1 - \cos\theta)^2}{\sin^2\theta} = \frac{(1 - \cos\theta)^2}{1 - \cos^2\theta}$
$= \frac{(1 - \cos\theta)(1 - \cos\theta)}{(1 - \cos\theta)(1 + \cos\theta)} = \mathbf{\frac{1 - \cos\theta}{1 + \cos\theta}} = \text{RHS}$। (इति सिद्धम्)
(ii) सिद्ध कीजिए: $\frac{\cos A}{1 + \sin A} + \frac{1 + \sin A}{\cos A} = 2\sec A$
$\text{LHS} = \frac{\cos^2 A + (1 + \sin A)^2}{(1 + \sin A)\cos A} = \frac{\cos^2 A + 1 + 2\sin A + \sin^2 A}{(1 + \sin A)\cos A}$
$= \frac{(\sin^2 A + \cos^2 A) + 1 + 2\sin A}{(1 + \sin A)\cos A} = \frac{1 + 1 + 2\sin A}{(1 + \sin A)\cos A} = \frac{2(1 + \sin A)}{(1 + \sin A)\cos A} = \frac{2}{\cos A} = \mathbf{2\sec A} = \text{RHS}$।
(iii) सिद्ध कीजिए: $\frac{\tan\theta}{1 - \cot\theta} + \frac{\cot\theta}{1 - \tan\theta} = 1 + \sec\theta\csc\theta$
$\sin\theta$ व $\cos\theta$ में बदलने पर:
$= \frac{\sin^2\theta}{\cos\theta(\sin\theta - \cos\theta)} - \frac{\cos^2\theta}{\sin\theta(\sin\theta - \cos\theta)} = \frac{\sin^3\theta - \cos^3\theta}{\sin\theta\cos\theta(\sin\theta - \cos\theta)}$
$= \frac{(\sin\theta - \cos\theta)(\sin^2\theta + \cos^2\theta + \sin\theta\cos\theta)}{\sin\theta\cos\theta(\sin\theta - \cos\theta)} = \frac{1 + \sin\theta\cos\theta}{\sin\theta\cos\theta} = \mathbf{1 + \sec\theta\csc\theta} = \text{RHS}$।
(iv) सिद्ध कीजिए: $\frac{1 + \sec A}{\sec A} = \frac{\sin^2 A}{1 - \cos A}$
$\text{LHS} = \frac{1 + 1/\cos A}{1/\cos A} = \frac{\cos A + 1}{1} = 1 + \cos A$
$\text{RHS} = \frac{\sin^2 A}{1 - \cos A} = \frac{1 - \cos^2 A}{1 - \cos A} = \frac{(1 - \cos A)(1 + \cos A)}{1 - \cos A} = 1 + \cos A$
$\text{LHS} = \text{RHS}$।
(v) सिद्ध कीजिए: $\frac{\cos A - \sin A + 1}{\cos A + \sin A - 1} = \csc A + \cot A$ (सर्वसमिका $\csc^2 A = 1+\cot^2 A$ प्रयोग से)
अंश व हर को $\sin A$ से भाग देने पर:
$= \frac{\cot A - 1 + \csc A}{\cot A + 1 - \csc A} = \frac{(\cot A + \csc A) - (\csc^2 A - \cot^2 A)}{\cot A - \csc A + 1}$
$= \frac{(\cot A + \csc A)[1 - (\csc A - \cot A)]}{\cot A - \csc A + 1} = \mathbf{\csc A + \cot A} = \text{RHS}$।
(vi) सिद्ध कीजिए: $\sqrt{\frac{1 + \sin A}{1 - \sin A}} = \sec A + \tan A$
अंश व हर में $(1 + \sin A)$ से गुणा करने पर:
$\text{LHS} = \sqrt{\frac{(1 + \sin A)^2}{(1 - \sin A)(1 + \sin A)}} = \sqrt{\frac{(1 + \sin A)^2}{1 - \sin^2 A}} = \sqrt{\frac{(1 + \sin A)^2}{\cos^2 A}} = \frac{1 + \sin A}{\cos A} = \frac{1}{\cos A} + \frac{\sin A}{\cos A} = \mathbf{\sec A + \tan A} = \text{RHS}$।
(vii) सिद्ध कीजिए: $\frac{\sin\theta - 2\sin^3\theta}{2\cos^3\theta - \cos\theta} = \tan\theta$
$\text{LHS} = \frac{\sin\theta(1 - 2\sin^2\theta)}{\cos\theta(2\cos^2\theta - 1)} = \tan\theta \times \frac{1 - 2(1 - \cos^2\theta)}{2\cos^2\theta - 1} = \tan\theta \times \frac{2\cos^2\theta - 1}{2\cos^2\theta - 1} = \mathbf{\tan\theta} = \text{RHS}$।
(viii) सिद्ध कीजिए: $(\sin A + \csc A)^2 + (\cos A + \sec A)^2 = 7 + \tan^2 A + \cot^2 A$
$\text{LHS} = (\sin^2 A + \csc^2 A + 2\sin A\csc A) + (\cos^2 A + \sec^2 A + 2\cos A\sec A)$
$= (\sin^2 A + \cos^2 A) + 2(1) + 2(1) + \csc^2 A + \sec^2 A$
$= 1 + 4 + (1 + \cot^2 A) + (1 + \tan^2 A) = \mathbf{7 + \tan^2 A + \cot^2 A} = \text{RHS}$।
(ix) सिद्ध कीजिए: $(\csc A - \sin A)(\sec A - \cos A) = \frac{1}{\tan A + \cot A}$
$\text{LHS} = \left(\frac{1}{\sin A} - \sin A\right)\left(\frac{1}{\cos A} - \cos A\right) = \frac{1 - \sin^2 A}{\sin A} \times \frac{1 - \cos^2 A}{\cos A} = \frac{\cos^2 A \times \sin^2 A}{\sin A\cos A} = \sin A\cos A$
$\text{RHS} = \frac{1}{\frac{\sin A}{\cos A} + \frac{\cos A}{\sin A}} = \frac{1}{\frac{\sin^2 A + \cos^2 A}{\sin A\cos A}} = \frac{\sin A\cos A}{1} = \sin A\cos A$
$\text{LHS} = \text{RHS}$।
(x) सिद्ध कीजिए: $\left(\frac{1 + \tan^2 A}{1 + \cot^2 A}\right) = \left(\frac{1 - \tan A}{1 - \cot A}\right)^2 = \tan^2 A$
प्रथम पद: $\frac{1 + \tan^2 A}{1 + \cot^2 A} = \frac{\sec^2 A}{\csc^2 A} = \frac{\sin^2 A}{\cos^2 A} = \mathbf{\tan^2 A}$
द्वितीय पद: $\left(\frac{1 - \tan A}{1 - \frac{1}{\tan A}}\right)^2 = \left(\frac{1 - \tan A}{\frac{\tan A - 1}{\tan A}}\right)^2 = (-\tan A)^2 = \mathbf{\tan^2 A}$
सभी पद परस्पर समान हैं! (इति सिद्धम्)
